# Архив старого tx_flash

Код сохранён только для просмотра. Четыре Rust-файла восстановлены без изменений
из коммита `ae0cac8`, исходный путь — `examples/stm32f401/src/bin/tx_flash/`.

Каталог находится вне `src/bin`, не объявлен Cargo-target и не участвует в сборке.
Пример не адаптирован под текущий API: использует удалённые `sat_core::comm`,
`Logger`, старый `FlashRing` и содержит незавершённый код в `main.rs`.
Это исторический образец, не рабочий пример нового Flash-стека.

Для нового кода используются `AsyncW25Q64`, `sequential-storage` и `QueueStorage`.
Восстановление архива не возвращает SD-логгер и удалённые core-трейты.
